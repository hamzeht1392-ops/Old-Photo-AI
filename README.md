# Old Photo AI 🖼️✨

An AI-powered tool for restoring and enhancing old photos.

Old Photo AI uses deep learning models to repair damaged images, remove scratches, restore missing areas, and improve old photo quality.

## Features

- 🖼️ Old photo restoration
- 🧹 Scratch and damage removal
- 🎨 AI color enhancement
- 🤖 SAM 2 segmentation
- 🧠 LaMa AI inpainting
- ⚡ CUDA GPU acceleration
- 🌐 Gradio web interface
