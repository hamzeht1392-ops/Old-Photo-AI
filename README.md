# ✨ معرفی پروژه

**Old Photo AI** یک پروژه مبتنی بر هوش مصنوعی است که تصاویر قدیمی، آسیب‌دیده و سیاه‌وسفید را بازسازی می‌کند.

این ابزار با استفاده از مدل‌های پیشرفته یادگیری عمیق می‌تواند:

- خط و خش تصاویر را حذف کند
- بخش‌های خراب یا حذف‌شده را بازسازی کند
- کیفیت عکس را افزایش دهد
- تصاویر سیاه‌وسفید را رنگی کند
- جزئیات از دست‌رفته را بهبود دهد

---

✅ بازسازی تصاویر قدیمی

# 🤖 مدل‌های هوش مصنوعی استفاده شده

## SAM 2

برای تشخیص و جداسازی بخش‌های مختلف تصویر.

## LaMa Inpainting

برای بازسازی قسمت‌های آسیب‌دیده و حذف‌شده تصاویر.

## DDColor

برای رنگی‌سازی تصاویر قدیمی و سیاه‌وسفید.

# 🛠️ نصب و اجرا

## روش پیشنهادی: Google Colab

### 1. دریافت پروژه

```bash
git clone https://github.com/hamzeht1392-ops/Old-Photo-AI.git
```

### 2. ورود به پوشه پروژه

```bash
cd Old-Photo-AI
```

### 3. نصب پیش‌نیازها

```bash
pip install -r requirements.txt
```

### 4. اجرای برنامه

```bash
python app.py
```

بعد از اجرای موفق، یک لینک Gradio ایجاد می‌شود.

لینک را در مرورگر باز کنید و شروع به بازسازی تصاویر کنید.
